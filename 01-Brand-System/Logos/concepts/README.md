# Logo concepts — PENDING APPROVAL

> **These are not the official Reale Revenue Systems logo.** The official geometric R mark and wordmark weren't available in this workspace. Per spec Part 1.2, these concepts stand in for it until the official files are supplied. Nothing here is a replacement.

| File | Use |
|---|---|
| `mark.ts` | Single source for the concept geometry, used by the site header, favicon, OG image and board |
| `rrs-mark-concept-a.svg` | Mark for dark backgrounds |
| `rrs-mark-concept-a-light.svg` | Mark for light backgrounds |
| `rrs-lockup-concept-a-dark.svg` / `-light.svg` | Mark + wordmark |
| `concept-board.png` | Review board (generated) |

**Construction:** a white stem (authority), a cobalt bowl (process) and a mint leg (recovered opportunity). The mint stays within the ≤5% rule.

**To adopt the official logo:** put the approved SVG/PNG files in `../approved/`, replace the paths in `mark.ts`, and run `npm run build`. The header, favicon and OG images all regenerate.
